# P3 阶段报告

完成任务：P3-1–P3-6。P4 进阶能力继续按官方接口与验证门推进。

## 改动

- 迁移 **029_inbox**：建议标题、依据、预览、首句、关联资料以现有 DEK 加密；类型、来源 ID、项目 ID、状态与时间为查询元数据。没有更改或删除原剪贴板、资源表中的内容。
- 捕获时本地规则识别报错、账号、秘密及 HMAC 重复；同一来源 10 分钟内去重，未处理建议不反复刷屏。收件箱按日期与类型筛选，显示计数和侧栏角标；可以编辑首句、开会话、保存资源、忽略或关闭规则，设置页可恢复规则。
- 从收件箱启动时立即进入会话，模型外发审批在那里完成；秘密仍由统一主进程扫描器拦截。规则不会自行启动模型。
- 启动和每 10 分钟运行本地整理：同项目 24 小时内多个 5 分钟窗口共同出现的 2–5 条建议合成片段、旧临时秘密提醒、相同保存副本去重、会话引用保护。所有整理动作均需要点击确认。
- 自动保留策略排除 `wb_session_clipboard_refs`；用户引用和 Agent 实际 `clipboard_read` 都登记引用。显式删除仍按原有确认流程。
- AI 找回：普通本地检索先显示；自然语言或 Ctrl+Enter 触发独立工具型 Host。外发只含脱敏查询句、当前日期、项目名称、分类枚举、来源应用名称；失败保留本地结果。筛选条件可移除。
- AI 整理：主进程准备带 5 分钟期限的脱敏预览；默认不选敏感项。只发已确认 ID 的那份预览，拒绝未知 ID、过期、重放、变化的记录；标题/摘要写入加密 `ai_meta` 并参与本地搜索。删除重复、合并片段建议在收件箱逐项确认。
- HUD 的 Tab 仅携带资料 ID 打开新会话；自然语言找回与 Ctrl+Enter 也支持 HUD。
- 资源详情与列表显示本地弱密码、重复密码、轮换提醒。复用现有 zxcvbn 强度评估与带密钥的 HMAC 索引；不会向渲染层或模型返回密码值。

主要文件：`src/db/{inbox-store.ts,migrations/inbox.ts,clipboard-store.ts}`；`src/main/{inbox,clipboard/ai.ts,clipboard/suggestions.ts,resources/health.ts}`；Harness 引用登记、workbench IPC/preload；`InboxPage`、`ClipboardOrganize`、`InboxRuleSettings`、剪贴板/资源/会话/HUD 页面与对应类型。
