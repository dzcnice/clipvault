# ClipVault AI 编程工作台使用说明

更新：2026-10-26，3.4.0 日常工作台。Windows 本地版，运行底座为官方 DeepSeek Harness。无需 Docker。技术审查见 [Claude 交接文档](CLAUDE-REVIEW-HANDOFF.md)。

## 打开与数据位置

直接运行 `dist/workbench-daily-20261026/win-unpacked/ClipVault Workbench Preview.exe`。同目录的其他文件必须保留，不能只复制一个 exe。安装包为 `dist/workbench-daily-20261026/clipvault-workbench-preview-3.4.0-setup.exe`，生成后未替用户安装或发布。程序名暂保留 Preview，以保持独立身份和资料路径兼容。

这份独立程序使用 `%APPDATA%/clipvault-workbench-preview`，不会自动打开旧版 ClipVault 的日常数据库。旧程序、旧数据和 OnSet 均保留。首轮欢迎页完成后进入工作台；原有凭证、片段、TOTP、健康检查等入口仍在侧栏。

为避免验证过程采集日常内容，交付预览资料的剪贴板监听默认暂停。在“剪贴板”页开启监听后即可记录新的复制。旧程序若同时运行，可能占用默认快捷键；可先从旧程序托盘退出，再使用新程序，或在设置中分配不冲突的快捷键。关闭主窗口会隐藏到托盘，托盘“退出 ClipVault”才是退出程序。

## 找回复制过的内容

在剪贴板中输入关键词，搜索完整历史；可按类型和来源查找，查看同一内容的复制发生记录。新捕获图片保留原图，列表使用缩略图。复制支持图片、路径及两者；文件路径只是引用，不等于备份了文件。

“置顶”调整展示顺序，“长期保存”创建独立副本。历史条数、天数、图片天数和容量策略不会清理长期保存项。选中需要的文本或 HTML，可带入新任务或追加到已有任务；清理原始历史不改变已经保存的任务快照。

## 保存一段账号或密钥资料

工作台选择“保存账号或密钥”，粘贴资料后点击“整理字段”，检查名称、项目、环境、地址、用途和字段，再保存。资料只在本机解析，未知格式会保留为敏感原始字段；它不会先发给模型分类。

较容易识别的输入格式：

```text
名称：示例后台
项目：我的项目
环境：development
用户名：example-user
密码：这里填写实际密码
地址：https://example.com/login
用途：下次登录后台检查配置
```

相同名称或地址会提示更新已有资源或另存独立账号；不会自动覆盖。修改同名秘密字段产生新版本，旧任务的授权和验证不会自动套用到新版。

下次在资源库按名称、用途、用户名、项目或环境找到它，分别复制账号、密码、Key 等字段，也可打开保存的网址。复制由主进程取字段，资源列表不批量包含秘密值。撤销后不能继续复制或让任务使用。

## 让 AI 处理项目

1. 在“项目”中选择具体代码目录，填写名称与环境。不要选择整个磁盘、用户目录或工作台自己的资料目录。
2. 回工作台交代目标与验收标准，选择同项目、同环境资源；也可以从剪贴板带入报错或代码。先保存草稿。
3. 点击运行，核对要发送给模型的目标与上下文。批准一次模型连接后，AI 可以读取项目普通文本；写文件、检查认证接口和运行测试分别有具体操作确认。
4. 查看修改前后内容、实际命令、输出和退出码。只有有效证据与当前文件一致时，才能确认验收。模型说“完成”本身不算完成。
5. 需要继续时填写“补充要求或新的报错”，可以追加剪贴板快照、调整资源，再保存补充并继续会话。运行或排队时先停止再改输入。旧要求与旧结果保留，不覆盖历史。

两个独立项目最多同时运行两个任务；相同目录、父子目录会排队，避免同时改同一份文件。重启后可恢复原 Session；曾经中断的写入会先比对文件，已经写好的内容不会再次自动覆盖。未确认结束的本机检查会要求核对进程，不能把一次异常停止当作已经安全结束。

任务表单的“常用任务模板”包含报错修复、代码审查、API 排查，可以把当前目标和验收标准保存为自定义模板，也可以删除不用的自定义模板。任务详情支持复制脱敏上下文，包含目标、补充、已选资料、文件差异和最近运行记录，便于交给 Claude 或 Codex；复制后仍应检查内容再粘贴到外部服务。

“添加文件或图片”会打开本机文件选择器。文字文件保存 UTF-8 快照；图片通过 Windows OCR 在本机提取文字，再展示发送内容。每次最多 10 个附件，文字文件不超过 100 KB，图片不超过 32 MB；待保存选择保留 30 分钟，过期需要重选。敏感配置、数据库、链接文件不能直接作为附件。当前为图片文字识别，不是模型直接看图；截图布局和纯图形仍需自行描述。

## 模型与本机检查

模型资源类型选“模型服务”，密钥单独保存为敏感字段，再到运行模型设置中关联。当前已经真实验证：用户指定端点 `https://caowo.fun/v1`、OpenAI Chat Completions 协议、`gpt-6-astra`。输入中的 `gpt-6-astar` 与服务实际模型名不同，交付配置使用后者的准确名称 `gpt-6-astra`。

官方 Harness 同样可以连接 Messages 协议服务；切换服务时需要地址、协议与模型名称匹配。请求次数和时间上限可配置，超过上限停止本次运行并保留结果。

本机检查支持：

```text
node --test settings.test.cjs
npm test
npm run test:unit -- --run
npm run typecheck
npm run lint
npm run build
```

运行使用随程序提供的 Node，npm 检查还需要本机能找到 npm。检查在项目普通文本副本中进行，复用已有 `node_modules`；不自动安装依赖，不把产物自动回写源目录。单次默认最长 2 分钟，源文件变化会让结果失效。

这是当前系统账户下的本机执行，项目脚本可以访问本机其他文件或网络；它不是操作系统沙箱。批准前需要信任该项目及其测试脚本。工作台不会把模型或资源密钥注入测试进程。

API 资源检查仅覆盖指定 HTTPS GET/Bearer 端点与预期响应文本。只有 HTTP 200 时显示连通事实，不能据此说账号有效或网页已登录。

账号资源可点击“登录助手”，打开独立临时窗口。只有保存的 HTTPS origin 可以联网；核对域名并确认后，填写页面中唯一可见的账号、密码输入框，不自动提交。验证码和 MFA 由你完成，关窗清理本次会话。跨域 SSO、依赖外部 CDN 或复杂表单可能无法加载/识别，此时使用“打开地址”及单字段复制。密码字段请命名为 `password` 或“密码”，并标记为秘密。

## 备份、恢复与旧数据

设置中可创建本机备份，或导出带独立密码的完整资料备份。备份包含数据库、资源版本、任务记录、已归档会话及仍存在的原图；会报告原图已缺失的情况。独立备份密码不改变活动资料库的密码或设备保护方式。

备份内的敏感值、任务内容与内嵌图片按 DEK 加密；部分名称、路径等元数据仍可见，不等于整个文件都是不可识别的密文。单图上限 32 MB、一次图片总量上限 512 MB。只有路径记录的外部文件、代码仓库、本机 npm 依赖和系统偏好不在资料备份里。

恢复会替换当前工作台的资料，先验证密码、数据库结构和图片哈希，再保存当前库备份与回退文件后切换。密码错误、内容损坏或来自不支持的未来版本时，在替换前失败。正在运行 AI 任务时需先停止。异机或跨资料目录恢复使用导出时的独立密码；仅设备保护的备份依赖原 Windows 账户和原资料目录的系统安全存储状态，不能仅凭一个数据库文件迁移。

本次没有自动导入旧版日常库。要接管旧历史，先在旧版本备份，再到资源库“把旧资料带进工作台”，填写旧备份密码、选择文件、查看预检数量并确认合并副本。它保留源库和当前数据，将剪贴板及复制发生记录、凭证、TOTP、标签分类、资源与项目重新加密后写入当前库。重复导入跳过；源记录发生变化时另存一份。当前模型配置与任务历史不被旧库替换。仅设备加密的旧备份若无法解锁，请从旧应用导出带独立密码的备份。

旧版本的数据库单文件备份可能不含图片原始内容；合并会报告缺失，不会跟随旧数据库中的任意外部路径读取文件。“恢复备份”仍是替换当前库，“合并副本”则只追加资料，请按目的选择。

新图片默认存为认证加密的 `.cvimg`。旧图片兼容读取，可在资源库点“备份并加密当前库的旧图片”：先备份，再逐张核对转换；仅清理默认图片目录内本应用生成的旧副本，外部原图保留。复制图片路径需要临时解密文件，它会在 10 分钟后清理；若来不及粘贴，可重新复制。异常退出遗留的临时导出会在下次启动清理。长期保存图片应另行导出，不要把临时路径当永久文件。

## 已知范围

活动 Harness 会话逐次写入加密数据库，重启后续接。当前仍没有跨设备同步、通用终端、自动部署、跨域无人值守登录或单任务多 Agent 编排。登录助手并非完整浏览器自动化。Windows 安装包未签名，其他操作系统未验收。详细证据、测试范围与限制见 [日常版本验收](WORKBENCH-DAILY-VALIDATION.md)。
