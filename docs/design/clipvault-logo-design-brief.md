# ClipVault Logo 设计文档

## 1. 文档用途

这份文档用于给 AI 生图工具提供统一、清晰、可执行的 Logo 设计指令，目标是为 **ClipVault** 产出一套适合桌面软件、安装包、应用图标、官网与文档封面的品牌标识方案。

这不是纯概念文档，而是可直接拿去喂给 Midjourney、Flux、Stable Diffusion、Ideogram、GPT Image 等工具的设计 brief。

## 2. 软件定位

ClipVault 是一个 **本地优先** 的桌面密码与剪贴板工作台，核心能力包括：

- 本地加密凭证管理
- 剪贴板历史与安全清空
- 恢复短语 / 生物识别 / 审计日志
- 团队协作、局域网共享、加密分享包
- Vera AI 助手
- CLI / HTTP API / SSH Agent 等开发者集成

一句话品牌定位：

**一个既安全、可信、克制，又现代、轻盈、专业的本地加密工作台。**

## 3. 现有视觉基因

当前项目已经存在一版图标，可作为连续性参考：

- 参考资源：`resources/icon-square.png`
- 当前图形语言：圆角方形 App Icon、保险箱 / 锁孔、钥匙、柔和玻璃感
- 当前配色方向：莫兰迪绿 + 莫兰迪粉 + 偏暖白底
- 当前 UI 气质：light theme 为主、液态玻璃、柔和、精致、偏生产力而非极客赛博

这意味着新 Logo 不建议完全跳到：

- 荧光赛博朋克
- 深紫霓虹
- 纯黑客风
- 区块链 / Web3 图标风
- 卡通化盾牌或廉价锁头素材风

## 4. Logo 应传达的品牌气质

### 关键词

- Local-first
- Secure
- Trusted
- Clean
- Professional
- Modern
- Lightweight
- Calm
- Intelligent
- Connected

### 中文气质描述

- 安全，但不沉重
- 专业，但不古板
- 智能，但不张扬
- 有温度，但不幼稚
- 偏桌面生产力工具，而不是金融 App 或游戏图标

## 5. 设计目标

目标不是画一个“锁”，而是画一个 **属于 ClipVault 的记忆点**。

Logo 最好同时满足：

1. 一眼能让人联想到“安全存储 / 凭证 / 本地保险箱”
2. 又能隐约带出“剪贴板 / 工作台 / 工具箱 / 桌面软件”的感觉
3. 小尺寸 16px、24px、32px 下仍然清晰
4. 既可做彩色 App Icon，也能降级成黑白单色符号
5. 看起来像真正的软件品牌，而不是一张功能插画

## 6. 推荐图形方向

建议优先让 AI 先探索下面 3 条主方向，再从中筛选。

### 方向 A：Vault Keyhole

最稳、最适合当前软件。

核心图形：

- 中心是一个简化的保险箱面板或金属卡片
- 面板中央是钥匙孔 / keyhole
- 顶部或角落有一个小的钥匙标签 / key tab
- 整体几何圆润、现代、克制

优点：

- 和当前图标延续性最好
- 容易在 installer / desktop icon 中落地
- 识别稳定，适合长期使用

风险：

- 容易变成“普通锁头图标”
- 必须避免过于通用和陈词滥调

### 方向 B：Clipboard Vault Hybrid

把“剪贴板”和“保险箱”做结构融合。

核心图形：

- 外轮廓像一个简化 clipboard / card / panel
- 中央是 keyhole 或 vault notch
- 可以在顶部做一个夹板结构，但必须极简

优点：

- 更能体现 ClipVault 的“剪贴板 + 凭证”
- 比单纯锁头更有产品特征

风险：

- 细节太多会在小尺寸下糊掉
- 如果夹板部分过强，会像办公文具品牌

### 方向 C：Secure Network Glyph

强调“本地安全 + 团队连接 + 工具平台”。

核心图形：

- 核心仍然是 vault / keyhole
- 外层加入极少量的连通结构、节点、环或桥接感
- 要非常克制，只能是辅助线索

优点：

- 更能体现 ClipVault 不只是密码库，还有协作与连接能力

风险：

- 一不小心会变成网络安全公司 logo
- 容易失去桌面工具的精致感

## 7. 推荐最终方向

### 首选建议：方向 A 和方向 B 的融合

最推荐的最终方向是：

**“一个简化的 vault/卡片面板，中央为 keyhole，外轮廓轻微带 clipboard/panel 暗示，顶部带一个非常简洁的钥匙标签。”**

原因：

- 既保留当前品牌连续性
- 又不只是“普通锁头”
- 能同时容纳“安全 / 本地 / 凭证 / 剪贴板 / 工具”这几层含义

## 8. 造型要求

### 应该做

- 轮廓简洁
- 重心稳定
- 中央构图
- 线条偏圆角
- 几何清晰
- 有高级感和细微层次
- 支持单色版本

### 不要做

- 不要卡通钥匙
- 不要复杂机械保险箱门
- 不要过多 3D 金属反射
- 不要赛博朋克霓虹紫
- 不要厚重黑客风
- 不要盾牌泛滥风
- 不要人物、动物、翅膀、火焰
- 不要在 icon 里塞文字 “CV”

## 9. 配色建议

以当前产品 UI 的颜色体系为主。

### 主色

- 莫兰迪绿：`#86A77C`
- 深一点的绿：`#6B8A62`

### 辅色

- 莫兰迪粉：`#D4A29C`
- 浅粉：`#E8CCC8`

### 中性底色

- 暖白：`#F7F3EF`
- 柔和灰白：`#ECE7E1`
- 深文字灰：`#2D2D32`

### 使用建议

- 优先绿为主、粉为辅
- 粉只做点缀，不要让 logo 变甜
- 不建议把 Vera 的紫色当主品牌色
- 可以用非常轻的玻璃雾面感，但不能太像 UI 截图

## 10. 质感建议

推荐 2 个可控方向：

### 方向 1：Soft Glass App Icon

- 柔和玻璃感
- 有轻微立体层次
- 适合桌面 App 图标
- 不能太花哨

### 方向 2：Flat Premium Mark

- 更平面、更品牌化
- 更适合官网、文档、favicon、印刷
- 适合作为最终标准 logo

建议 AI 先出两套：

- 一套 App Icon 风格
- 一套更平面、适合品牌手册的标准图形

## 11. 输出规格

让 AI 一次就尽量产出这些版本：

1. 方形 App Icon
2. 单独符号版
3. 浅底彩色版
4. 深底彩色版
5. 黑白单色版
6. 横向 lockup 预留版

### 建议画面规范

- 画布：1:1
- 主版本：1024x1024
- 背景：纯白 / 透明 / 柔和浅底都可测试
- 图形居中
- 不带文字优先

## 12. 推荐 AI 提示词

下面的 prompt 已经按 ClipVault 的真实品牌方向整理好。

### Prompt A：主推方案

```text
Design a premium logo for a desktop software brand called ClipVault, a local-first encrypted credential and clipboard workspace. Create a centered square app icon with a minimalist vault plate or secure card panel, a clean keyhole in the middle, and a subtle small key-tab accent on the top edge. Blend the feeling of a secure vault and a clipboard panel without becoming literal office stationery. Use soft Morandi sage green and dusty blush pink accents, warm off-white background, refined liquid-glass softness, rounded geometry, calm and trustworthy product-design aesthetics, highly legible at small sizes, no text, no mascot, no cartoon, no cyberpunk, no generic shield, no photorealism, clean negative space, polished but restrained.
```

### Prompt B：更平面、更品牌化

```text
Create a flat premium logo mark for ClipVault, a local-first secure desktop app for credentials, clipboard history, and encrypted workflows. The symbol should combine a simplified vault panel, a keyhole, and a subtle clipboard/card silhouette into one clean geometric icon. Use Morandi green as the primary color with a soft blush accent, minimal detail, strong silhouette, elegant spacing, modern productivity-software branding, suitable for app icon, favicon, installer icon, and monochrome use. No text, no 3D chrome, no heavy gradients, no hacker clichés, no stock lock icon.
```

### Prompt C：强调连接与协作

```text
Design a modern desktop-software logo for ClipVault. The icon should suggest secure storage, local trust, and lightweight collaboration. Use a simple vault or keyhole core, with a very subtle connected-ring or node structure that hints at encrypted teamwork, but keep the shape compact and elegant. Morandi sage green, warm white, and a small blush accent. Calm, refined, trustworthy, local-first, minimal, iconic, scalable, no words, no busy details, no blockchain style, no cybersecurity corporate shield.
```

为桌面软件 ClipVault 设计一套高级感 logo。它是一个本地优先的加密凭证与剪贴板工作台，需要体现安全、可信、本地存储、专业、轻盈、现代的感觉。图形以简化的保险箱面板或安全卡片为主体，中间有清晰钥匙孔，外轮廓带一点 clipboard 或 panel 的暗示，顶部可以有一个非常简洁的小钥匙标签。整体要几何化、圆角化、留白干净、适合做 app icon，也要支持黑白单色版本。主色用莫兰迪绿，辅色少量莫兰迪粉，底色暖白，允许轻微液态玻璃感，但不要变成 UI 插画。不要卡通，不要赛博朋克，不要紫色主色，不要通用盾牌，不要写文字，不要复杂金属质感，不要廉价锁头素材感。

## 15. 生图时的操作建议

推荐用这个顺序：

1. 先出黑白符号草图
2. 选中结构最强的一版
3. 再上 Morandi 绿 / 粉配色
4. 再尝试 app icon 玻璃感版本
5. 最后补透明底和深色底适配

不要一开始就让 AI 直接做：

- 复杂 3D
- 光效拉满
- 带文字品牌稿

先把“形”做对，再做“质感”。

## 16. 选稿标准

一轮出图后，优先保留满足以下条件的版本：

- 缩小后仍能看清核心轮廓
- 不像通用密码管理器模板
- 有明显“品牌感”而不是“功能图标感”
- 和当前莫兰迪玻璃 UI 相容
- 黑白版也成立
- 既可做桌面应用图标，也可做文档头图

## 17. 不建议的方向

以下方向不建议继续投入：

- 纯盾牌 + 锁
- 纯钥匙图标
- 太像银行、保险或区块链项目
- 太像聊天机器人或 AI 公司
- 太像办公文具或剪贴板 App
- 细节太多、依赖质感才能成立

## 18. 推荐你最终要拿到的成果

如果 AI 出图顺利，建议最后至少整理出：

- `1` 个主 Logo
- `1` 个 App Icon 版本
- `1` 个黑白版
- `2~3` 个备选方案

其中主 Logo 最好满足：

**安全保险箱感 60% + 剪贴板/工作台感 20% + 协作/智能感 20%**

这会比“只画一个锁”更像 ClipVault。
