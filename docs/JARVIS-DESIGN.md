# Jarvis：常驻身边的剪贴板管家（v3.5 设计）

更新：2026-10-27。前置：`HARNESS-NATIVE-DESIGN.md`、`DEV-SPEC-HARNESS-NATIVE.md` v1.1、P0–P4 已完成。

## 1. 用户要什么

用户原话归纳：

- 打开就能直接问，不必先选项目。
- 允许联网。
- 截图后直接问 AI。
- 账号资料能快速登录。
- 剪贴板图片要看得见。
- 账号串要能识别出来，并提示存为资源。
- 像贾维斯一样，一直在身边、懂上下文、会主动搭把手。

**原则**
- 「主动」只来自用户自己的动作（复制、截图、按热键），绝不在后台偷看屏幕。
- 主动建议只是轻提示，不打断用户，也不自动执行。

## 3. 体验设计

### 3.1 三个入口，一个 Jarvis

| 入口 | 触发 | 用途 |
|---|---|---|
| **浮窗** | `Alt+Space` | 搜索 / 粘贴剪贴板与资源；直接输入问题，回车问 Jarvis；斜杠命令 |
| **截图问** | `Alt+Shift+S` | 调起系统截图（Win+Shift+S 同款框选），截完浮窗自动带图打开，光标在输入框 |
| **主窗口** | `Ctrl+Space` | 完整会话、剪贴板、资源、收件箱 |

浮窗里的回答以流式显示，提供「复制 / 粘贴到前台 / 在主窗口继续」三个操作。

### 3.2 直接对话

- 新会话页去掉「选项目 → 选权限 → 开始」三步，直接就是输入框，回车即建会话并发送。
- 项目与权限缩成输入框下方的两个小选择器，默认是 **随手问**，记住上次选择。
- **随手问**是内置项目：
  - 使用应用私有空目录，看不到任何代码文件。
  - 允许联网（`web_search` / `web_fetch`），可以 @ 剪贴板和资源。
  - 默认权限「逐次确认」。
- **代码项目**：在项目设置中单独开启「允许联网查资料」，默认关闭。

### 3.3 审批：每个会话只问一次发送

- 「发送消息并使用项目上下文」在同一会话里只在第一轮确认一次。
- 以下情况需要重新确认：模型、服务地址、项目或权限改变；计划模式切换。
- 写文件、运行命令、使用资源、联网抓取私网地址（直接拒绝）仍然逐个动作处理。

### 3.4 看得见的剪贴板

- **列表**：图片行显示 40px 缩略图。
- **详情**：显示大图，点击后全屏查看，支持滚轮缩放和拖动。
- **「图片」分类**：切换为网格画廊（160px 卡片，悬停显示来源与时间，双击复制）。
- **本机 OCR**：
  - 新图片在后台排队识别（Windows 原生 OCR，不联网），文字加密保存。
  - 搜索可以命中图片里的文字。
  - 详情里可以复制识别出的文字。

### 3.5 截图问 AI（识图）

- 图片只存在主进程的加密存储里。Host 和会话事件里只有 `[[图片:<id>]]` 标记。
- 桥接发请求给模型时把标记展开：
  - OpenAI 兼容协议展开为 `image_url`。
  - Anthropic 协议展开为 `image`。
- 消息里同时附带本机 OCR 文字。模型不支持识图时，自动去掉图片、只保留文字重试一次，并在会话中说明。
- 图片发送前会缩到最长边 1568px、转成 JPEG。图片里的秘密无法自动识别，所以只在用户明确附图时发送。

### 3.6 快速登录

- 在浮窗里搜索账号资源，回车即「自动输入」：粘贴用户名 → Tab → 粘贴密码。**不自动提交**，验证码留给 `Alt+Shift+V`。
- 浮窗按前台窗口标题和进程名匹配资源的名称、地址或域名，把最可能的账号排在最前。
- 原有「凭证」一键并入「资源」：
  - 字段角色自动标注（用户名 / 密码 / 验证码种子）。
  - 原记录保留只读。
- 剪贴板识别到账号串（`邮箱|密码|…`、`账号----密码`、`user:pass`）后：
  - 列表遮挡显示。
  - 收件箱提示「存为资源」，点开即预填录入审阅。

### 3.7 主动但不打扰（灵动岛轻提示）

| 用户动作 | 提示（5 秒后自动收起） |
|---|---|
| 复制报错 | 问 Jarvis 怎么修 |
| 复制账号串 | 存为资源 |
| 截图 | 问这张图 |
| 复制长英文 | 翻译 |

每类提示都可以在设置里关闭。

### 3.8 记忆「关于我」

- 设置里有一段「关于我」（加密存储），注入每个会话的系统提示，例如称呼、常用语言、技术栈、回答风格。
- Jarvis 可以用 `memory_propose` 提议记住一条，用户在对话里点「记住」才写入。

## 4. 性能

- **Host 保温**：一轮结束后 Host 不退出，保温 5 分钟。下一句直接复用进程，免去冷启动和恢复。锁库、切换模型、应用退出时回收。
- 缩略图懒加载，带 LRU 内存缓存；画廊使用虚拟化分页。

## 5. 安全边界（新增）

- **联网**：
  - 一律由主进程出网，Host 不直接联网。
  - 只允许 http(s)，拒绝 localhost / 私网 / 链路本地地址，对重定向也逐跳校验。
  - URL 与查询中出现已知秘密时拒绝。
  - 抓取内容限 2 MB，标注为外部不可信数据。
- **识图**：只发送用户明确附带的图片，不自动截屏。
- **记忆**：只能由用户写入或由用户确认写入。
- **自动输入**：只把内容输入到前台窗口，不自动提交；60 秒后恢复原剪贴板。

## 6. 实施顺序

1. **J1**：随手问 + 直接对话 + 联网 + 每会话一次授权 + Host 保温。
2. **J2**：图片缩略图 / 大图 / 画廊 / OCR 搜索 + 截图问 + 识图注入。
3. **J3**：账号串识别与提示 + 凭证并入资源 + 自动输入登录 + 前台匹配。
4. **J4**：浮窗问 Jarvis（流式回答、斜杠命令、粘贴回前台）。
5. **J5**：灵动岛轻提示 + 「关于我」记忆。
6. **J6**：会话置顶 / 归档 / 删除，设置 / 更多 / 项目页 v3 化，版本 3.5.0，质量门与打包。

**暂不做**
- 语音唤醒：官方仅有实验包，本机模型体积大，后续单独评估。
- 跨设备同步：与本地优先原则冲突。

## 8. 从原版 ClipVault 导入（发布前补齐）

原版 3.x 的免密保险库用 Electron safeStorage 包裹数据钥匙（`v10` + AES-256-GCM），密钥在原版资料目录的 `Local State` 中、受 Windows DPAPI（当前用户）保护。新版是另一个程序，因此在 `src/main/legacy-import.ts` 中按同样格式在本机解开：

1. 自动定位 `%APPDATA%\clipvault`（也可以手动选目录），连同 WAL 复制到新版资料目录下的临时工作目录，`VACUUM INTO` 得到一致快照；原版只读。
2. DPAPI 解开 `os_crypt.encrypted_key`，再解开 `vault_meta.encrypted_dek` 得到原版数据钥匙；主密码模式改用原版主密码。
3. 原版图片（明文或 CVIMG）按合并格式封装进快照；原路径失效时按文件名在原版 `images` 目录里查找。
4. 复用「旧资料合并」：确认对话框显示数量，合并前备份当前资料，原记录不覆盖，重复跳过；结束后删除临时工作目录、清零钥匙。
5. 已经合并过同一份原版资料（同一把钥匙留下的合并索引）时不再提示，手动导入时给出可能重复的警告。

证据：`legacy-import.integration.test.ts`（合成原版资料：钥匙解包、文字/凭证/TOTP/图片合并、原版文件哈希不变、重复导入全部跳过、错误用户与损坏钥匙拒绝）。在用户真实原版资料上做了只读演练：全新临时资料目录在约 1 秒内导入剪贴板 508 条、凭证 7 条、图片 124 张，515 条记录全部可解密，原版数据库与 Local State 前后哈希一致；演练目录已删除。
