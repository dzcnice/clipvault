# ClipVault 快捷键 · v3

## 全局快捷键

在任意应用中可用（macOS 将 `Ctrl` 换为 `Cmd`）：

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+Space` | 显示 / 隐藏主窗口 |
| `Ctrl+Shift+F` | 打开窗口并聚焦搜索 |
| `Ctrl+Shift+N` | 新建凭证 |
| `Ctrl+Shift+P` | 粘贴最近一条剪贴板历史 |
| `Alt+Space` | 召唤 / 收起命令 HUD |

设置页「快捷键」表格与上述默认值同步（来自 `src/main/shortcuts/registry.ts`）。

## 应用内

| 操作 | 方式 |
|------|------|
| 复制 | 双击列表项，或悬停后点复制 |
| 图片：仅图 / 仅路径 / 图+路径 | 悬停图片项右侧三个按钮 |
| 置顶 / 删除 | 悬停后对应图标 |
| 命令面板 | 应用内快捷入口 / HUD |

## 托盘

| 操作 | 行为 |
|------|------|
| 点击托盘图标 | 显示 / 隐藏主窗口 |
| 关主窗口 | **隐藏到托盘**，继续监听剪贴板 |
| 托盘 → 退出 ClipVault | **真退出** |
