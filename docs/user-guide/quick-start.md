# 快速开始

ClipVault v3 是单机个人版：打开即用，**没有日常主密码门槛**。

## 安装

### Windows

下载 `clipvault-x.y.z-setup.exe` 后运行。

- 默认创建开始菜单 / 桌面入口
- 可在设置里打开开机自启
- 正式代码签名仍依赖发布环境中的证书

### macOS

下载 `.dmg` 后拖入「应用程序」。公证依赖 Apple 证书；未公证时按系统提示允许打开。

### Linux

提供 AppImage / deb / snap。

## 首次启动

1. 欢迎页：说明本地优先、无登录
2. 快捷键与 HUD
3. 可选：从其它密码管理器导入
4. 可选：写下 BIP39 恢复短语（灾难恢复，不是日常登录）

保险库由操作系统 `safeStorage`（Windows DPAPI / macOS Keychain）自动打开。旧版主密码库可以一次性迁移。

## 日常使用

- 复制内容会进入剪贴板历史（可排除应用、限制条数）
- 检测到 API Key 等模式时会询问是否收入凭证箱
- 复制凭证后可按设置自动清空系统剪贴板
- 关主窗口默认驻留托盘

更完整的能力说明见 [README](../../README.md)。
