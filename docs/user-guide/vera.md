## 三层权限模型

| 层级 | 名称 | 可访问数据 | 触发方式 |
|------|------|-----------|----------|
| L1 | 默认（只读元数据） | 凭证标题 / 分类 / tag / 创建时间 | 始终允许 |
| L2 | 会话（临时解锁） | L1 + **单个**凭证 value（需用户点击确认） | 每次对话开始弹一次解锁 |
| L3 | 自动化 | L1 + L2 + 执行主进程工具（复制 / 新建 / 删除） | 每个操作独立二次确认，可配置白名单 |

![三层权限示意](placeholder.png)

默认 Vera 处于 **L1**。当 Vera 尝试访问更高权限时，会弹出一个**权限请求对话框**，说明：

- 它要访问哪条凭证
- 将发送给哪个模型
- 是否记录审计日志

你可以选择「仅本次」、「本会话内自动」、「拒绝」。

## 占位符脱敏

这是 Vera 的核心隐私机制。

### 原理

```
用户输入：
  "帮我把 GitHub Token 放进环境变量 GITHUB_TOKEN"

Vera 预处理（本机完成）：
  替换为 "{CRED_a1b2}"，建立映射 {CRED_a1b2 → ghp_xxx}

发送给 LLM：
  "帮我把 {CRED_a1b2} 放进环境变量 GITHUB_TOKEN"

LLM 返回：
  "你可以运行 export GITHUB_TOKEN={CRED_a1b2}"

Vera 后处理（本机完成）：
  反替换 → "你可以运行 export GITHUB_TOKEN=ghp_xxx"
```

![占位符流程图](placeholder.png)

### 保证

- 明文 **永不** 离开本机
- 模型看到的始终是 `{CRED_xxx}` 占位符
- 占位符映射表仅在内存保留一次响应周期

### 限制

某些场景（例如让模型解读凭证语义）不适用占位符。Vera 会在这些场景显示额外警告并要求明确同意。

## 模型配置

在「设置 → AI」中：

- **DeepSeek**（推荐）：`api.deepseek.com`，按 token 计费，速度快
- **OpenAI**：`gpt-4o-mini` / `o1-mini`，需要自带 Key
- **本地 Ollama**：零云端依赖，localhost:11434

所有 API Key 使用 vault DEK 加密后存入 `vera_settings` 表。

### 预算保护

可为每个模型设置**月度 token 上限**。达到 80% 会在 HUD 显示提示；100% 会自动降级到本地 Ollama（如可用）或暂停。

## 审计日志

在「审计 → AI」查看：

- 每次调用的时间、模型、token 消耗、权限层级
- 占位符映射（本地 keystore 加密）
- 用户授权记录

支持按关键词 / 日期范围 / 凭证 ID 过滤，导出为 JSON。

## 常见问题

**Q：Vera 会主动同步凭证到云端吗？**
A：不会。Vera 完全在本机加密访问，仅在用户明确 L2/L3 授权时才读取凭证 value，且始终替换为占位符后发送。

**Q：我能禁用 Vera 吗？**
A：可以。在「设置 → AI」关闭总开关即可。

**Q：本地 Ollama 模型推荐？**
A：`qwen2.5:7b` / `llama3.1:8b`（8GB 显存起步）。
