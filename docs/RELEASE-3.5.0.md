# ClipVault Workbench Preview 3.5.0 · Jarvis（预发布）

这是**预发布版**。它是一个独立的新程序「ClipVault Workbench Preview」，可以和原版 ClipVault 3.3 同时安装。原版不会自动升级到这里，需要手动下载安装。

## 新功能

- **直接对话，可以联网**：打开就是输入框，回车就问。默认是「随手问」：不碰任何代码目录，可以搜索和读取公开网页（由本应用代为访问，拒绝局域网地址）。代码项目也可以在项目里选，每个动作都会先问你。
- **截图问 AI**：`Alt+Shift+S` 框选截图后直接交给 Jarvis；也可以在输入框粘贴或拖入图片。模型不支持看图时，会改用本机识别出的图片文字。
- **Jarvis 浮窗**：`Alt+Space` 里直接输入问题回车。回答按 `Alt+Enter` 可以粘贴回刚才的窗口。支持 `/翻译` `/总结` `/解释` `/改写` `/截图`。
- **看得见的剪贴板**：列表缩略图、大图查看、图片网格画廊；图片文字在本机识别，可以按文字搜到截图。
- **快速登录**：识别 `账号|密码`、`账号----密码`、`邮箱:密码` 这类账号串，遮挡并提示存为资源。在浮窗里选中账号回车会自动输入「用户名 → Tab → 密码」，不会自动提交；有验证码时按 `Alt+Shift+V` 粘贴。
- **记住你**：在「更多 → Jarvis」里写「关于我」。Jarvis 提议记住的内容只有你批准才会写入，带密码或密钥的一律拒绝。
- **轻提示**：复制报错、截图、账号串之后，给一个可以点的小建议。同类 30 秒内最多一次，每类都能关闭。
- **会话管理**：会话可以置顶、归档、彻底删除。
- **从原版 ClipVault 导入**：自动找到原版的资料目录，导入剪贴板、凭证、TOTP 和图片。原版只读不改，重复的记录会跳过。

## 安装

1. 下载下方的 `clipvault-workbench-preview-3.5.0-setup.exe`。
2. 安装包**没有代码签名**，Windows SmartScreen 可能会拦截，点「更多信息 → 仍要运行」即可。
3. 打开后，到「资源库」填写自己的模型服务地址和密钥。支持 OpenAI 兼容服务与 Anthropic 协议；安装包里不带任何密钥。
4. 用过原版 ClipVault 3.x 的话，资源库顶部会提示「发现原版 ClipVault 的资料」，点「导入」即可。如果原版设置过主密码，到「资源库 → 数据导入与导出」里填写密码后导入。

## 数据与安全

- 资料加密保存在本机 `%APPDATA%\clipvault-workbench-preview`，和原版分开存放。
- 账号、密码、密钥只保存在本机。模型只能看到资源的名称和字段角色，看不到具体值。
- 只有你主动附上的图片才会发给模型，不会在后台截屏。
- 从原版导入时，用 Windows 的数据保护机制在本机解开原版资料，**必须是同一个 Windows 用户**。

## 已知限制

- 只支持 Windows。
- 安装包未签名；这个预发布版不提供自动更新，请到 Releases 页面下载新版本。
- 能不能看图、联网质量好不好，取决于你使用的模型服务。
- 图片文字识别依赖 Windows 自带的 OCR 语言包。
