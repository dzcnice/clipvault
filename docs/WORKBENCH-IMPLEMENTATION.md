## 实施约束

- 开发和测试只操作当前仓库、专用测试目录及独立工作台预览数据，不运行日常旧库迁移，不读取日常凭据。用户明确提供的模型密钥只用于指定端点联调及新工作台配置。
- 新数据使用现有 SQLite 迁移执行器与 DEK；资源列表不包含秘密值；手动复制由主进程完成。
- 模型密钥与项目凭据分别管理，敏感资料本地整理；模型只接收用户选定的上下文。
- 不根据模型文字宣称任务通过；记录工具结果、差异、退出和验证状态。
- 未验证的执行隔离不得自动放行任意终端。需要系统权限变更时，先完成可评审方案再向用户明确说明。
- 不新增全局依赖、修改系统权限、强制推送或发布。当前仓库已有改动全部保留。
