## 实施与验收顺序

- [x] 1. 依赖安全更新：固定受支持的 Electron / 构建工具与受影响依赖；保留清单和锁文件回退副本，审计前后均通过基础守卫；npm audit 0。
- [x] 2. 图片加密：新图片使用现有 DEK 认证加密，旧图兼容读取、无损转换；复制路径产生可控临时导出；备份与恢复支持新格式。
- [x] 3. Harness 活动会话加密：使用官方持久化服务契约，事件写入主进程加密数据库，拒绝越界或跨会话访问；真实模型任务跨进程恢复同一 Session 通过。
- [x] 4. 日常资料衔接：备份预检、只增不覆盖的合并入口、重复导入去重、失败回滚；原数据与当前工作台新数据同时保留；合成不同 DEK、TOTP、图片与发生记录验收通过。
- [x] 5. 本地 OCR 与文件上下文：图片文字本机识别、文字文件快照、明确外发预览与敏感内容过滤，错误与取消可恢复；WinRT 实测通过。
- [x] 6. 常用工作流程：任务模板、外部工具上下文导出、账号登录辅助与明确域名确认；保持逐次授权和单目录写入保护。
- [x] 7. 日常可用性与安全回归：87 文件/465 项原生测试通过；原生窗口、组件交互及键盘、加载/错误、最小窗口、退出与重启、构建、安装包及随包运行时通过。未把它当作人工全矩阵验收。
- [x] 8. 更新指南、Claude 交接、实际验收证据和剩余外部条件；备份独立预览资料后启动 3.4.0，未覆盖原日常应用。
